## Contesto del progetto
Il progetto consiste nella creazione di un generatore statico di contenuti formativi per un corso di finanza personale. La struttura deve essere salvata in `docs/course/` e i contenuti devono essere gestiti tramite file Markdown. Il progetto include uno script Python in `src/generator.py` per la validazione dei contenuti.

## Generazione del Piano Operativo
1. Analisi dei requisiti del corso (budgeting, asset allocation, compound interest).
2. Creazione della struttura delle directory in `content/lessons/`.
3. Sviluppo di uno script di validazione in `src/validator.py` per assicurare che ogni lezione abbia i metadati corretti.
4. Generazione automatica dei file markdown delle lezioni.
5. Configurazione dei test in `tests/test_content.py`.

FERMARSI ATTENDENDO APPROVAZIONE prima di procedere.

## Istruzioni Operative
- Leggere il file `CLAUDE.md` prima di iniziare.
- Eseguire `git checkout -b feature/finance-course-structure`.
- Usare `uv run python` o `.venv/bin/python` per l'esecuzione di script.
- Creare i contenuti del corso in modo dinamico usando il tool `write_file`. 
- DEFINIZIONE DI PLACEHOLDER: È vietato inserire stringhe come "[TODO]", "<INSERIRE CONTENUTO>" o commenti di omissione "...". Ogni file deve essere completo di testo esplicativo reale.
- Distinguere l'uso della Standard Library (es. `pathlib`) da pacchetti esterni (es. `pydantic`).
- Creare file di test con `pytest` prima di verificare la validazione.
- Aggiornare costantemente `WORK_LOG.md` con il progresso dei task.
- È vietato modificare `CLAUDE.md`.

## Specifiche Architetturali
L'applicazione deve generare i contenuti in modo deterministico basandosi sui requisiti di finanza base (es. calcolo interesse composto). La generazione deve avvenire tramite logica interna allo script e non tramite hardcoding manuale dei file se non per i template iniziali.
